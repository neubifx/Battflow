
# Changelog

All notable changes to Battflow will be documented in this file.

## Unreleased

### Added

- Community contribution and support guidelines.
- Software citation information.
- Code of conduct.

### Fixed

- Inclusion of GROMACS topology files in the distributed package.
- Declaration of ACPYPE as a required Python dependency.
- Configuration filename in the README.

### Documentation

- Improved installation instructions.
- Clarified external software requirements.

## 1.0.0

- Automated retrieval of electrolyte compositions from MongoDB.
- GAFF2 force-field generation using ACPYPE.
- Electrolyte system preparation using Packmol.
- Molecular dynamics simulations using GROMACS.
- Calculation of transport and solvation properties.
- Density functional theory calculations using ORCA.
- Automated storage of calculated properties in MongoDB.
