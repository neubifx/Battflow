
# Contributing to Battflow

Contributions to Battflow are welcome, including bug fixes, new features,
documentation improvements and suggestions for extending the workflow.

## Reporting issues

Please report bugs through the
[GitHub Issues page](https://github.com/neubifx/Battflow/issues).

When reporting an issue, please include:

- Battflow version.
- Operating system and Python version.
- Versions of relevant external software.
- Steps to reproduce the issue.
- Relevant configuration files and error messages.
- Expected and observed behaviour.

Please remove sensitive information, such as MongoDB credentials,
before sharing configuration files.

## Contributing code

To contribute to Battflow:

1. Fork the repository.
2. Clone your fork and create a new branch.
3. Follow the installation instructions in the README and install Battflow
   in editable mode.
4. Implement and test your changes.
5. Update the documentation and include tests where appropriate.
6. Submit a pull request describing your changes.

Please follow the existing coding style and include docstrings for new
functions and methods.

Changes affecting computational methods or property predictions should
include relevant scientific justification and validation.

## Seeking support

For questions regarding installation, configuration or workflow execution,
please use the
[GitHub Issues page](https://github.com/neubifx/Battflow/issues).
